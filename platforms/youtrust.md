# Platform: YouTrust

YouTrust（ユートラスト）は「友達経由の信頼ベースキャリアSNS」。
LinkedInやWantedlyとは違い、**1人称・体験ベース・温度高め**の発信が機能する。

---

## 仕様

| 項目 | 値 |
|---|---|
| 文字数上限 | 公式上限はあるが、**実用は 800〜2,000字推奨** |
| 改行 | 自由。1段落 3〜5行で空行を入れるのが読みやすい |
| URL | リンクプレビュー対応。OGPがそのまま反映される |
| 画像 | 投稿に添付可。1〜複数枚。横長が表示きれい |
| ハッシュタグ | **0〜2個**。多用は浮く（YouTrust文化として） |
| メンション | `@` でユーザー指定可 |
| 動画 | 直貼り可。短尺推奨 |

---

## 文化と読者層

- **キャリア文脈**が強い。「採用」「組織」「働き方」「個人の挑戦」が反応取りやすい
- **コーヒーチャット文化**: 投稿を見て「話聞きたい」とDMが来る前提で書く
- **温度高め × 一人称**: 「私はこう思った」「最近こんなことやってます」というトーンが歓迎される
- **マウンティング系は浮く**: 「年商◯億」「No.1」みたいな表現は逆効果
- **採用ニーズの匂わせOK**: ただし露骨にならないように

### 想定読者

- 同業のマーケ・営業・PdM
- 転職を考えている人〜将来的に動くかもしれない人
- 取引先・顧客（個人として接点がある人）

## 推奨フォーマット

```
[1段落目: フック / 結論先出し]
（1〜3行で「何の話か」をはっきりさせる）

[2段落目: 背景・文脈]
（なぜこの話をしているか、どんなシチュエーションか）

[3〜4段落目: 本文]
（学び / エピソード / 数字 / 失敗談）

[5段落目: 抽象化したメッセージ]
（読者にとっての持ち帰り）

[6段落目: CTA]
（コメント / DM / 「興味ある人話しましょう」）

#ハッシュタグ（任意・2個以内）
```

### 強いフックの例

- 「最近やらかしたんですけど、◯◯」
- 「3ヶ月前の自分に教えたいこと」
- 「これ、業界の人と話してて意外と知られてなかった」
- 「正直に言います。◯◯、しんどかった」

### 弱いフック（避ける）

- 「皆さんお疲れ様です」
- 「いつもお世話になっております」
- 「マーケティングについて投稿します」

## CTA（YouTrust特化）

- 「コメントで意見ほしいです」
- 「同じ経験ある人いたらお話したい、コーヒーいきましょう」
- 「◯◯について深掘りしたいので、知見ある方DMください」
- 「うちで一緒にやってくれる人探してます。興味ある人いたらぜひ」

---

## ハッシュタグ運用

つけるなら以下から選ぶ（カテゴリ別）：

- マーケ系: `#BtoBマーケ` `#リードマーケ` `#マーケティング`
- 仕事系: `#働き方` `#組織` `#マネジメント`
- 採用系: `#採用` `#キャリア` `#インターン募集`
- Highlite固有: `#Highlite` `#ハイライト`

複数つける場合も**最大2個**。3個以上は浮く。

---

## やってはいけないこと

- 全く同じ投稿をLinkedInからコピペ → 文脈が違うので必ずトーン調整
- 過剰な絵文字スパム → 「✨」「！」程度に抑える
- 数字の偽装・誇張 → コミュニティが小さいのですぐバレる
- 顧客名の特定可能な記述 → NG
