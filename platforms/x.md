## 仕様

| 項目 | 値 |
|---|---|
| 文字数上限 | 280字（無料）／ 25,000字（X Premium）。**実用は 140字以内** が拡散最強 |
| 改行 | OK。空行で段落分けすると読まれる |
| URL | 1つにつき短縮されて自動で23字相当 |
| 画像 | 最大4枚。1枚なら正方形（1080×1080）か16:9（1600×900）推奨 |

## 文化と読者層

- **冒頭1行で全てが決まる**: TLでスクロール中に止まるかどうか
- **数字と「えっ」がコンビ**: 「3ヶ月で◯%改善した、やったのは1つだけ」
- **自虐・冷笑OK**: コミュニティ文化として機能する
- **長文を1投稿に詰めない**: スレッドで分けると読まれる
- **絵文字 0〜2個**: 多すぎると軽く見える

### 想定読者

- マーケ実務家・SaaS PdM・スタートアップ層
- 同業のフリーランス・コンサルタント
- 情報感度の高い経営層

## 推奨フォーマット

### A. シングルポスト（拡散狙い）

```
[フック1行]
（数字 or 結論 or 逆説）

（空行）

[補足1〜2行]

（空行 or 不要）

#HashTag #HashTag2
```

100〜140字に収める。280字フルに使うと「重い」と感じられる。

### B. スレッド（深い学びを伝える）

本文には `(1/2)`・`1/2`・`1/N` などの連投番号を入れない。順番は管理用の見出しで示し、2投稿目以降を親投稿への自己返信としてつなぐ。

**親投稿**
```
[フック投稿: 何の話か + 結論]
（数字 or 「3つあった」「やったのは1つ」）
```

**続きの投稿**
```
[論点1]
```

```
[論点2]
```

```
[論点3]
```

**最後の投稿**
```
[まとめ + CTA]
（リンク or 「詳しく書きました」）
```

スレッドは**3〜7投稿が読まれやすい**。10超えると離脱増。

### 強いフックの例

- 「BtoBマーケで、3年やってやっと気づいたこと。」
- 「リード獲得CV率を2倍にしたの、変えたのは1箇所だけだった。」
- 「『マーケが効かない』と言ってる会社の99%が見落としている指標。」

→ 最後の「99%」みたいな煽り表現は voice-tone.md で原則NGなのでXでも避ける。

### 弱いフック（避ける）

- 「私たちHighliteは〜」（自分から入らない）
- 「皆さん知ってますか？」（読者に教えを請う形は古い）

## CTA（X特化）

- 「リプで意見ほしい」
- 「詳しく書いた → [リンク]」
- 「RT歓迎」（あえて煽らない方が伸びるケース多）
- 「DMで話しましょう」（営業臭が出ないように）

## ハッシュタグ運用

2〜3個、自然に。

- マーケ系: `#BtoBマーケ` `#リードマーケティング` `#SaaSマーケ`
- 自社: `#Highlite`
- 業界トレンド: `#マーケティング` `#GoToMarket`

本文の文脈に自然に溶け込ませる or 末尾にまとめる。両方OK。

---

## やってはいけないこと

- 280字フル使い切り → 重い
- ハッシュタグ5個以上 → スパム感
- リプ欄での過度な営業 → 即ブロック対象
- 競合への直接的な批判 → 大炎上リスク
- 「99%が知らない」「衝撃の事実」系の煽り → voice-tone.md でNG
