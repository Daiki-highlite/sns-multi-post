# Platform: Facebook

Facebookは**実名制・コミュニティベース**。Highliteの場合は**経営層〜先輩マーケター層**にリーチしやすい。
最近は若年層離れが進んでいるが、**40代以上のビジネス層**には依然として有効。

---

## 仕様

| 項目 | 値 |
|---|---|
| 文字数上限 | 63,206字（実用は **300〜600字** が伸びやすい） |
| 改行 | 多用OK。1段落 2〜4行で空行 |
| URL | リンクプレビュー対応。OGP重要 |
| 画像 | 1枚 or アルバム。OGP（1200×630）or 正方形が映える |
| ハッシュタグ | **1〜2個**。多用は浮く |
| メンション | `@` で個人・ページ指定可 |
| 動画 | ネイティブ動画は再生数稼げる |

---

## 文化と読者層

- **実名 × 顔出し前提**: 知り合いが読む。距離感は近い
- **長文よりエピソード重視**: 「あったこと」をストーリーで語る
- **写真+本文** が王道。テキストオンリーは伸びにくい
- **絵文字は使ってOK**: 適度に使うと親しみが出る
- **コメント文化が強い**: コメントへの返信も含めて1投稿

### 想定読者

- 経営層・マーケ責任者（40代以上）
- Highlite社員の知人・前職同僚
- 顧客企業の担当者（個人として接点がある人）
- 採用候補者の親世代（採用文脈で副次的にリーチ）

## 推奨フォーマット

```
[フック: 1〜2行]
（OGP画像が出るなら、フックは画像と被らない補足にする）

（空行）

[本文: 200〜400字程度]
（ストーリー形式 / 実体験 / 写真と紐づくエピソード）

（空行）

[抽象化 or CTA: 1〜2行]

（任意）#HashTag1 #HashTag2
```

### 強いフックの例

- 「先日、◯◯という出来事がありました」
- 「久々に◯◯を見直していて、気づいたことがあります」
- 「これ、社内で議論になった話なのですが」

### 弱いフック（避ける）

- 「LinkedInに書いた内容ですが」（媒体間の使い回し感が出る）
- 「お忙しいところすみません」（ビジネスメール調）

---

## CTA（Facebook特化）

- 「コメント欄でぜひ意見聞かせてください」
- 「同じこと感じてる方、いいねかコメントもらえると嬉しいです」
- 「詳しい記事はリンクから」（リンクは本文に貼ってOK）
- 「興味ある方、メッセンジャーでもお気軽に」

---

## ハッシュタグ運用

つけるとしても1〜2個。なくてもOK。

- 業界系: `#BtoBマーケ` `#リードマーケティング`
- 自社: `#Highlite`

X / LinkedIn のように大量に並べると浮く。

---

## やってはいけないこと

- 全く同じ投稿の他媒体からのコピペ感 → 媒体ごとに冒頭1〜2行を必ず変える
- 「シェア・いいねお願いします」のお願い → 古臭く感じられる
- ハッシュタグ5個以上 → ノイズ
- 政治・宗教・センシティブ話題 → 個人の判断で投稿しない

---

## 画像戦略

Facebookは**画像があるかないか**でリーチが大きく変わる。

- OGP画像が出る投稿（URLあり）→ 自動でカード表示
- 写真投稿 + 本文 → リーチ高
- テキストのみ → リーチ低

OGPジェネレータ（`ogp/generator.html`）でHL公式画像を生成して必ず添付推奨。
