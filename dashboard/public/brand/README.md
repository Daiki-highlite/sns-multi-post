# Highliteブランド素材

公式の [Brand Guidelines](https://highlite.co.jp/brand-guidelines/) に従って使用しています。

- `highlite-logo-color.svg`：https://highlite.co.jp/downloads/brand/highlite-logo-color.svg
- `highlite-symbol-color.svg`：https://highlite.co.jp/downloads/brand/highlite-symbol-color.svg

原本の形・色・縦横比を保持しています。商標・著作権はHighliteに帰属します。

日本語はGoogle FontsのZen Kaku Gothic New（400・500・700）を参照し、欧文は端末のAvenir / Avenir Nextを使用します。フォントファイルは同梱していません。
