## 残る確認

利用開始時に実行を依頼された原稿について、各SNSの現在の予約画面で日時・本文・画像・投稿主体を照合する。X連投は予約一覧で全件と順序・返信関係が確認できること、指定時刻後の公開結果を確認する。確認不能なら結果不明に残して再実行しない。SNS側の表示変更や投稿形式制限は画面の手順に従って停止・報告する。
